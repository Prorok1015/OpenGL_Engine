#1185: edt::document_manager keeps the open previews as members (std::vector<previewable_document*> of the open ones and a
unique_ptr to a document that failed to open), its list of preview kinds holds per kind the documents made for it, so the
size of document_manager and of edt::editor_context, which holds it by value, changes: the editor layout key changes
(editor_layout_revision 1 -> 2, the sizes of the two types move it by themselves), game_editor modules must be rebuilt.
New non-virtual export document_manager::previews(); preview() now returns the active preview, else the one opened last.
edt::asset_preview_desc gains `bool multiple` at its end (a preview whose every source gets a document of its own and whose
documents do not replace each other). add_preview is public and a module reaches it through editor_context::asset_kinds(),
so the module may build an asset_preview_desc itself: the type is now in editor_layout_types (next to
module_asset_preview_desc), a later change of its size moves the editor layout key. No vtable changes: the pins stay.
