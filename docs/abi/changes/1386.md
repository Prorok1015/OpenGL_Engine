#1386: new exports (non-virtual): rnd::render_system::check_shader_program (builds the program of a .shader.desc without a material and without
touching the program cache; returns std::vector<rnd::shader_problem>, which is in the layout key) and the overload
rnd::shader_config::load(constant_data, resource_system&, binding_table, load_options) (the 3-argument load stays, with the same behaviour); new type
rnd::shader_config::load_options (a flag, passed by const reference). rnd::ShaderManager (internal) gains check() and a private build_program.
No type of the layout key changes and no vtable changes: the layout key stays (no layout_revision change).
A module that calls check_shader_program or the 4-argument load needs an engine with #1386.
