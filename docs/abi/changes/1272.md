#1272, #1273: rnd::material_instance_cache's constructor gains a third parameter, `res::resource_system* resources =
nullptr` (the cache watches the shader descs of its instances and reloads them; nullptr watches nothing), and new exports
problems() and problems_generation() (material-level "shader/load" failures, one per shader and material).
rnd::build_compiled_material gains an overload that takes the material_shader_state to compile with; the old export
stays and delegates to it. rnd::render_system::shader_problems() now also returns those material-level shader load
failures (shader_problems_generation() moves with them). No type changes: the layout key stays.
