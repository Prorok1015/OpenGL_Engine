#1327: new scene API for the frustum query of spatial queries (EPIC-81 US-81-C): `scn::spatial_world::overlap_frustum` (non-virtual member) and the free `scn::overlap_frustum` and `scn::screen_rect_view_projection` exports.
They take and return only types that are already in the layout key or fixed-size values (`glm::mat4`, `glm::vec2`, `scn::ray_filter` by reference, `std::vector<entt::entity>&` as the out list, as `raycast_all` does with `scn::ray_hit`); no new value type, no change of a keyed type, no vtable change: the layout key stays (no layout_revision change).
`scn::detail::spatial_backend` (private to the scene library, nothing pinned) gains a pure virtual `overlap_frustum`.
A module that calls them needs an engine with #1327.
