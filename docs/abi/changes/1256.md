#1256: wnd::window_system and wnd::window_listener_interface (a module registers its own listener through
add_event_listener and the engine calls it) are pinned: wnd::window_system_abi_revision and
wnd::window_listener_interface_abi_revision (1) join gs::module_layout_key (layout_revision 19). window_system's
add_event_listener, remove_event_listener, get_event_listeners, set_close_request_handler and request_close are new
exports instead of inline code over its members; no vtable or member changes. A module built before #1256 is refused
until it is rebuilt.
