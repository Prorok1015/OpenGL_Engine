#1200: rnd::material_desc (rnd_material_desc.h, scn::material_desc by alias) loses the members vertex_shader, fragment_shader
and geometry_shader and gains res::res_handle<rnd::shader_desc> shader, so its size and member offsets change, and
rnd_material_desc.h now includes rnd_shader_desc.h. rnd::shader_desc::config() const becomes
config(const std::vector<std::string>& extra_defines = {}) const (a new exported symbol, the old one is gone), and shader_desc
now overrides desc_base::deserialize (no new virtual function). No type of
gs::module_layout_key changes, so the layout key and layout_revision stay. material_desc and shader_desc are not in the key,
so they are not module API until they enter gs::module_layout_key (as with 1199.md); a module built against the old header
that touches these members must be rebuilt.
desc::migration_context gains a member at its end (the id_of lookup) and a second constructor taking a
desc::migration_id_lookup; the old constructor stays. New exports: migration_context::id_of,
desc::desc_system::migration_ids (non-virtual) and rnd::migrate_material_v1 (rnd_material_migration.h). The material_desc
version becomes 2. migration_context is passed to steps by reference and built only by the engine, so a module's step
keeps working; it is not in gs::module_layout_key.
rnd::material_compile_context gains `std::optional<material_shader_state> shader` at its end, and rnd_material_compiler.h
adds rnd::material_shader_state and the export rnd::read_material_shader: build_compiled_material reads the shader once and
hands that state to compile. A compiler a module implements still compiles; one that ignores the member reads the shader
itself, as before.
layout_revision 18: desc::field_schema (in gs::module_layout_key) gains `bool reference_only` after `offset`, its last member,
and desc::field_attr_data gains the same flag with the builder field_attr::reference_only(): a desc_ref that takes only a
reference to a file. operator== of field_schema compares it, a runtime schema reads it as "reference_only", the JSON schema
of an agent offers a string or {guid, path} for it, and check_override refuses an inline desc object there. material_desc's
shader is the first such field.
