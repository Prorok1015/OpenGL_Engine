#1236: new export desc::desc_system::stamp_inline_version (static, non-virtual), called by the template
desc_ref_traits<res::res_handle<T>>::to_json, which a module instantiates: an inline desc written from memory gets "__type"
and the current "__version" of its type. No type of gs::module_layout_key changes, so the layout key and layout_revision
stay. A module built before #1236 keeps writing inline descs without "__version"; read back, they are version 1 and go
through the steps of their type, as before. It needs a rebuild to write them versioned.
New export scn::compose_component_json(cnode, parent, const desc::desc_system&): the overload that gives the typed
objects of serialize(parent) without "__version" the current one; the reconcile of a prefab instance composes so, which
also covers the inline descs a module built before #1236 writes.
