#1487 (EPIC-66 US-66-A): new exported class res::save_service (include_base/snk/resource/res_save_service.h, base-only, not installed) with res::save_status, res::save_result, res::save_options and res::save_stage: a slot written under user://saves/ with a backup and the result as a value.
Nothing a game module reaches: the header is not in the SDK, the engine has no accessor for it and no type of it is in the layout key (the key stays, layout_revision unchanged). save_result holds a std::string and save_options a std::function, so #1489 (US-66-C) gives a module its access with types that may cross the module boundary, and adds them to the key there.
A module that calls it needs an engine with #1487.
