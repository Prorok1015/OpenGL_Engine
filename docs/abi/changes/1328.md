#1328 (shape queries, EPIC-81 US-81-D, part 2): `scn::overlap_shape`, `scn::overlap_point` and `scn::closest_point` exports (and the same three as `scn::spatial_world` members). The value types `scn::shape` (a tagged volume: sphere, capsule or box, built with `make_sphere`/`make_capsule`/`make_box`), `scn::shape_kind` and `scn::point_hit` join the layout key (a module builds a shape; the engine writes a point_hit).
layout_revision 29.
`scn::detail::spatial_backend` (private to the scene library, nothing pinned) gains pure virtuals `overlap_shape`, `overlap_point` and `closest_point`.
A module that calls them needs an engine with this change.
