#1201: rnd::driver::driver_interface::create_shader gains a second parameter `shader_build_log* log = nullptr` (the
compiler's and linker's logs; new types rnd::driver::shader_stage_log and shader_build_log), so its vtable slot changes.
driver_interface is not pinned and has no <interface>_abi_revision (it is not in gs::module_layout_key): no layout
revision changes, but a module that implements or calls create_shader through the old slot must be rebuilt.
New exports: rnd::render_system::shader_problems_generation and shader_problems (non-virtual), with the new type
rnd::shader_problem (rnd_shader_problem.h). rnd::shader_config::load_result gains `problems`, `sources` and `program` at
its end; rnd::ShaderManager (internal) gains problems() and problems_generation(); the test backend
rnd::driver::null::driver gains judge_shaders_with and a member at its end. No type of gs::module_layout_key changes:
the layout key stays.
