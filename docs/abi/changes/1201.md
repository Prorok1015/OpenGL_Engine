#1201: layout_revision 21: rnd::driver::driver_interface::create_shader gains a second parameter
`shader_build_log* log = nullptr` (the compiler's and linker's logs; new types rnd::driver::shader_stage_log and
shader_build_log), so the driver's vtable changes. Modules reach the driver through the inline
rnd::render_system::get_driver(): a module built before #1201 would call create_shader through the old slot, so it is
refused until it is rebuilt. The driver interfaces have no pin of their own yet (#1298).
New exports: rnd::render_system::shader_problems_generation and shader_problems (non-virtual), with the new type
rnd::shader_problem (rnd_shader_problem.h). rnd::shader_config::load_result gains `problems`, `sources` and `program` at
its end; rnd::ShaderManager (internal) gains problems() and problems_generation(); the test backend
rnd::driver::null::driver gains judge_shaders_with and a member at its end.
