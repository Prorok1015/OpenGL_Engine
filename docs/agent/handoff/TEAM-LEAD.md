## Процесс

- Сессии пишут в `wip/*`, открывают draft PR в `aibranch`. Перед каждой задачей — DISCOVER→PLAN на issue, план согласует координатор; архитектурные развилки — владельцу с рекомендацией простыми словами.
- Агенты не собирают и не запускают локально: проверка — CI на PR.
- Независимое ревью каждого PR отдельным агентом (для политики, MCP, путей, конкурентности, импорта — ревью безопасности); раунд правок проверяется повторно. Дизайн-доки — техническое ревью до вопросов владельцу.
- Стопки PR не глубже 2–3; правки ревью нижних PR — до новых PR.
- Слияние: быстрый уровень CI (6 job) → снять draft → полный CI 13/13 → `git merge-tree --write-tree origin/aibranch <head>` без конфликтов → smoke «diff:» на baseline (1×0.000%, 4×0.139%, 1×1.073% — с #645 (папка input/ сдвинула браузер ассетов; до этого 1.218%)) → squash с `sha`, trailers `Co-Authored-By` + `Claude-Session` → закрыть issue, отметить AC → сообщить сессии.
- Два частых падения CI — см. `CODE_CONVENTIONS.toon` (R"json(...)json"; значения по умолчанию у полей при частичной brace-инициализации).
- Если ветка PR отстала и `aibranch` получил изменения в тех же файлах, перед full — merge `aibranch` в PR, чтобы full проверял объединённый код.
- Ловушки, найденные в эти дни: тест, молча выключенный `#if` (декодер не собирался, #665 — теперь `#error`/`FATAL_ERROR`); шаги хоста с `headless_target_fps 0` и лимитом кадров (ставить 1000, #673); `<windows.h>` в общем тестовом хедере ломает имена клавиш (#679); `"…"` внутри обычного строкового литерала; новое поле без инициализатора по умолчанию ломает чужие агрегатные инициализации (`-Wmissing-field-initializers`, #687); тест, пинящий текущую minor-версию (`== 4`), падает при подъёме — пинить `>=` (#687); `friend`-повтор `SNK_API`-функции без `SNK_API` — риск C2375 на MSVC (#689); колбэк «уровень перезагружен» до разыменования миров видит 0 диагностик (#685).
- Порядок мержа при общих файлах (часто `edt_editor_system.cpp`): мержить по одному, остальные вливают `aibranch` после каждого мержа; очередь объявлять сессиям заранее, чтобы не гонять лишние круги.
- Перезапуск задачи CI — один раз и только при инфраструктурном сбое до тел тестов; второй сбой считается настоящим.
- Конфликт с `aibranch`: сессия вливает `aibranch` merge-коммитом (не rebase, не force-push), затем снова CI.
- Эталонные PNG smoke меняются только решением владельца.
- CodeRabbit игнорируется.
- Ничего важного только локально: все ветки на GitHub (остатки — `wip/archive/*`), планы и решения — комментариями в issues.
- Логи CI: `gh api repos/Prorok1015/OpenGL_Engine/commits/<sha>/check-runs`, `.../actions/jobs/<id>/logs`. GraphQL недоступен: draft снимается через `POST .../pulls/<n>/ccr/ready_for_review`.
- Отчёты владельцу — по-русски, простыми словами.
