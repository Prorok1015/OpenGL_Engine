## Процесс

- Сессии пишут в `wip/*`, открывают draft PR в `aibranch`. Перед каждой задачей — DISCOVER→PLAN, план согласует координатор; архитектурные развилки — владельцу с рекомендацией.
- Агенты не собирают и не запускают локально: проверка — CI на PR.
- Независимое ревью каждого PR отдельным агентом (для политики, MCP, путей, конкурентности — ревью безопасности); раунд правок проверяется повторно.
- Слияние: быстрый уровень CI (6 job) → снять draft → полный CI 12/12 → `git merge-tree --write-tree origin/aibranch <head>` без конфликтов → smoke «diff:» на baseline (1×0.000%, 4×0.146%, 1×0.404%) → squash с `expectedHeadSha`, trailers `Co-Authored-By` + `Claude-Session` → закрыть issue, отметить AC → сообщить сессии.
- Конфликт с `aibranch`: сессия вливает `aibranch` merge-коммитом (не rebase, не force-push), затем снова полный CI.
- Эталонные PNG smoke меняются только решением владельца.
- CodeRabbit игнорируется.
- Ничего важного только локально: все ветки на GitHub (остатки — `wip/archive/*`), планы и решения — комментариями в issues.
- Логи CI: `gh api repos/Prorok1015/OpenGL_Engine/commits/<sha>/check-runs`, `.../actions/jobs/<id>/logs`. GraphQL недоступен: draft снимается через `POST .../pulls/<n>/ccr/ready_for_review`.
- Отчёты владельцу — по-русски, простыми словами.
