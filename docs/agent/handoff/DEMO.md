# Демо по итогам этапа D

**Связано:** #55 (ручная проверка редактора на Windows) · хендофф `PHASE0-STATUS.md`

## Зачем и когда

- Этап D почти целиком перестраивает внутренности: RHI R2–R7, контексты миров, каркас редактора, task system. CI проверяет это на Linux через программный рендер (llvmpipe) и на Windows только сборкой и тестами. **На настоящей видеокарте под Windows после этой волны редактор никто не запускал.** Демо — первая такая проверка, и она же закрывает #55.
- **Когда:** одно демо в конце этапа D (решение владельца 2026-10-19 — промежуточного не будет).
- **Чего ждать:** «тот же редактор на новом фундаменте». Новых видимых функций немного. Undo — M3, Play/Stop — M4, ИИ-агент к концу D — только чтение.

## Как получить сборку

1. **Основной путь — без локальной сборки.** Запустить workflow **Release** (`.github/workflows/release.yml`, `workflow_dispatch`) на ветке `aibranch`. Результат — артефакт `SnakeEditor-windows-x64` (zip с `editor.exe`, `config/`, `res/`, `res_core/`), его нужно скачать и распаковать.
2. **Запасной путь — локальная сборка**, если артефакт не запускается или нужен отладчик. Нужны Visual Studio 2022 (C++), CMake ≥ 3.25, Ninja и Git:
   - `git submodule update --init --recursive`;
   - `cmake --preset dev-release` и `cmake --build build/dev-release --target editor` из Developer PowerShell;
   - запуск: `build/dev-release/Editor/editor --config Editor/config/editor.cfg`.
