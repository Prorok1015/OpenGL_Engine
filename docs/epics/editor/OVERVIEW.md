# Theme: Editor Features

## Суть

Итеративное развитие редактора сцен — UI-панели, инструменты работы с объектами,
pipeline ассетов, сохранение сцен. Эпики 01–07 составляют первое поколение
редактора (до перехода на desc-driven архитектуру из темы `desc-driven`).
